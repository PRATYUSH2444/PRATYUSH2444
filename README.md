## 🚀 Projects

### 🏆 BioPod — IoT Waste Processing System
**VOIS Tech Innovation Marathon 2.0  |  Top 30 / 850+ Teams  |  5-Month National Program**

IoT-based organic waste processing system using insect bio-decomposition. Real-time monitoring and control via Arduino microcontrollers and Blynk IoT — sensor data, actuator control, live alerts. Includes a MERN stack web dashboard with rule-based threshold logic for decomposition rate estimation and operational efficiency.

`MERN Stack` `Arduino` `Blynk IoT` `Environmental Sensors` `Weight Sensors`

### 🌐 Taste of Homes — Cloud Kitchen Platform
**Live Production Site  |  [tasteofhomes.in](https://tasteofhomes.in)**

Full customer journey — menu browsing, cart, checkout, order confirmation. Integrated Razorpay for live UPI (GPay, PhonePe, Paytm), credit and debit card transactions. Built and managed end-to-end order flow with automated confirmations and a kitchen-side tracking panel.

`WordPress` `WooCommerce` `Elementor` `Razorpay`

### 🔐 Intelligent Phishing Detection System
**AI/ML — In Progress (2026–Present)**

Privacy-preserving phishing URL classifier using Federated Learning — model trained across distributed nodes without sharing raw data. Ensemble of Random Forest + XGBoost with Mutual Information for feature selection. Evaluated on AUC, F1-score, Precision, and Recall targeting deployment-grade accuracy.

`Python` `Scikit-Learn` `XGBoost` `Federated Learning` `Pandas` `NumPy` `Matplotlib`
